# Clean Project Structure

This project maintains a clean repository structure. 

## In This Folder (APPLIASSIST/)
✅ **Source code, configs, and essential files only**
- Ready to push to GitHub

## Outside This Folder (Same Level)
External folders that are **NOT** included in the repository:
- `../test-files/` → Test files and scripts
- `../documentation-files/` → Documentation and audit reports  
- `../backup-files/` → Backup files and references

See `PROJECT_STRUCTURE_GUIDE.md` at the root level for full details.

## Quick Commands
```bash
npm run dev       # Start development
npm run build     # Build for production
npm test          # Run tests (from ../test-files/)
```
