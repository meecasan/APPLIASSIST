# APPLIASSIST: Appliance Repair Service Management System

## Project Description
Appliassist is a web-based system that solves problems in appliance repair services such as manual booking, miscommunication, and lack of service tracking.  

It allows customers to easily request repair services, track service status, and communicate with technicians.  
Technicians can manage job requests and schedules, while store owners can manage appliance parts and inventory in one platform.

The system provides a centralized and organized way of handling appliance repair services and parts ordering to improve efficiency and communication between users.

---

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP/Node.js/Python
- Database: MySQL

## Installation Guide


```
### 1. Clone the repository
```bash
git clone https://github.com/meecasan/APPLIASSIST.git 
```
### 2. Enter Project Folder
```bash
cd APPLIASSIST
```
### 3. Install Dependencies
```bash
npm install
```
### 4. Run the Application
```bash
npm start
```
### 5. Open in Browser
```bash
http://localhost:3000
```
